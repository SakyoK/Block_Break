# Python製ブロック崩しゲーム

## 制作時期
2025年12月下旬 ～ 2026年1月上旬

## 作品の説明
このプロジェクトは、PythonとPygameライブラリを使用して制作されたオーソドックスなブロック崩しゲームです。
オブジェクト指向プログラミングの学習を目的としており、パドル、ボール、ブロックといった各要素をクラスとして定義し、それらをメインのゲームループで制御する構成をとっています。

操作方法は非常にシンプルで、マウスを左右に動かすことで画面下部のパドルを操作できます。
ボールがパドルに当たると跳ね返り、画面上部に配置された赤いブロックを壊していきます。
全てのブロックを消去することがこのゲームの目標です。
もしボールが画面の下端を越えてしまった場合は、ミスとなりボールが中央からリセットされます。

プログラムの設計においては、メンテナンス性を高めるためにファイルを役割ごとに分割しました。
`constants.py` で画面サイズや色などの定数を一括管理し、`sprites.py` でゲーム内オブジェクトの振る舞いを定義しています。
これにより、例えばブロックの色を変更したり、ボールの速度を調整したりする作業が容易に行えるよう工夫しました。
PygameのSpriteグループ機能を活用することで、当たり判定の処理を簡潔に記述している点も特徴の一つです。
今後は、スコア機能の追加やステージの難易度設定、サウンドエフェクトの実装などを行い、よりゲームとしての完成度を高めていきたいと考えています。

## 使用ライブラリ
* pygame

## 実行方法
1. 依存ライブラリのインストール: `pip install -r requirements.txt`
2. ゲームの起動: `python main.py`
